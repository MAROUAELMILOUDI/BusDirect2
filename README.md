# BusDirect2

## Description

BusDirect2 est une application web de réservation de billets de bus. Elle permet aux utilisateurs de consulter les trajets disponibles, de rechercher un voyage et de réserver leurs sièges.

## Fonctionnalités

- Affichage des trajets disponibles.
- Recherche et filtrage des trajets.
- Pagination des résultats.
- Consultation de la cabine du bus.
- Affichage des sièges libres et occupés.
- Sauvegarde des données avec LocalStorage.

## Technologies utilisées

- HTML5
- CSS3
- JavaScript (ES6+)
- Tailwind CSS
- LocalStorage

## Installation

1. Cloner le projet :

```bash
git clone https://github.com/MAROUAELMILOUDI/BusDirect2.git
```

2. Ouvrir le dossier du projet dans VS Code.

3. Lancer `index.html` avec Live Server.
